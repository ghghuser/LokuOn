# LokuOn（録音）

Windows 11 用の録音ソフトです。インストール不要（ポータブル）で、設定はテキストの `settings.ini` に保存されます。

- PC内部音（WASAPIループバック）・マイク・ASIO入力を録音
- mp3 / aac(.m4a・.aac) / flac / wav / opus に対応（エンコードは同梱の FFmpeg）
- 長時間録音向け：録音しながらその場でエンコードして保存（途中で落ちても録音が残ります）
- 日本語のファイル名・タグに対応

## ダウンロードと起動

1. このリポジトリの **Releases**（または Actions の Artifacts）から `LokuOn-win-x64.zip` をダウンロード
2. 好きなフォルダに展開（デスクトップでも USB メモリでも可）
3. `LokuOn.exe` を起動

ZIP の中は `LokuOn\LokuOn.exe` と `LokuOn\ffmpeg\ffmpeg.exe` だけです（単一exe）。.NET のインストールは不要です。削除するときはフォルダごと消すだけです。
初回起動時に `settings.ini` が作られます。バックアップはこのファイルをコピーするだけです。

## GitHub でのビルド手順

1. GitHub で新しいリポジトリを作る（Private でOK）
2. 展開したこのフォルダの中身（`src`、`tests`、`.github`、`README.md`、`.gitignore`）を **Add file → Upload files** でアップロード
   - `.github` フォルダが見えない場合は、エクスプローラーで「隠しファイルを表示」にしてください
3. **Actions** タブで「Build LokuOn」が動き、数分で完了すると `LokuOn-win-x64` というファイルが **Artifacts** に出ます
4. Releases に公開したいときは、Releases → **Draft a new release** でタグ（例 `v1.0.0`）を作って公開すると、ZIP が自動で添付されます
   （または、タグを作成して push しても同じです）

## 画面の使い方

| 場所 | 内容 |
| --- | --- |
| 上部 | プリセットの選択・保存・削除、JSON のエクスポート／インポート。右上の ⚙ ボタンで、テーマ（ライト／ダーク／システム）・背景の効果（Mica／アクリル、Windows 11）・最小化したときの動作（タスクバーに残す＝初期値／タスクトレイにしまう）・バージョン・GitHub・かんたんな使い方 |
| 入力デバイス | 最大3つ。🎤マイク（名前順）→ 🔊スピーカー＝PC内部音（名前順、WASAPIループバック）→ ASIO の順に表示。Windows の既定のデバイスは名前の末尾に「＊」。初期値は既定のマイク（前回の選択を優先）。デバイスごとにゲイン調整とメーター付き |
| 複数デバイス | 初期値は「ミックスして1ファイル」。切り替えで「デバイスごとに別ファイル」 |
| 音質・形式 | 形式、ビットレート、サンプリングレート、チャンネル（例: 320kbps / 48.0kHz / stereo）。最後に選んだ形式は次回も維持 |
| 保存 | 保存先フォルダ（初期値 `ドキュメント\LokuOn\Rec`）、日付フォルダ（初期値 `{yyyy}-{MM}-{dd}`、録音を始めた日で固定）、ファイル名テンプレート（下の変数。名前を付けて保存・削除・初期に戻すができます） |
| 分割 | ボタンでワンタッチ分割／「○分ごと」の自動分割（0=しない。1440分まで）／無音検出での分割／安全上限（初期値 24時間。1つのファイルがこれを超える前に必ず分割）。「○分ごと」と安全上限は、短いほうが先に働きます（画面に実際の間隔が出ます） |
| タグ | タイトル・アーティスト等（空欄なら付けません）。「トラック番号をタグに入れる」は初期値オフ |
| 録音 | ● 録音 / ■ 停止 / ❚❚ 一時停止・再開 / ✂ 分割。一時停止中の音と時間はファイルに入りません（つなぎ目は短いフェードで「プツッ」を防止）。メーター、ピーク警告（CLIP）、波形、空きディスク容量を表示 |
| ファイル一覧 | 作成したファイルの一覧。ダブルクリックで再生。右クリックで「エクスプローラーで開く」「名前の変更」「ごみ箱へ」など。複数選択可 |
| 再生 | 再生／一時停止／停止、シークバー、再生速度（0.5〜2倍。音程は変わりません）、音量 |

録音中にウィンドウを閉じようとすると確認が出ます。最小化したときの動作は ⚙ で選べます（初期値はタスクバーに残す）。「タスクトレイにしまう」を選ぶと、トレイのメニューから録音開始・停止・一時停止・分割ができます。トレイのアイコンは、待機中はアプリのアイコン、録音中は赤い点付きになります。

### ファイル名テンプレート

初期値（日時形式）: `{Date} {Time} (No.{No}).{ext}` → `2026-11-01 13：05：09 (No.917).flac`

トラック形式: `No.{No}-Track{Track:000}_{Start}-{End}({Length}).{ext}` → `No.917-Track001_00：00-36：25(36：25).flac` / 分割後 `No.917-Track002_36：25-40：00(03：35).flac`

| 変数 | 内容 |
| --- | --- |
| `{No}` | 録音ナンバー。録音が終わると自動で +1。アプリを終了しても保持 |
| `{Track}` `{Track:000}` | トラック番号（分割ごとに +1）。`000` で桁数を指定 |
| `{Start}` `{End}` `{Length}` | 開始・終了・長さ（秒単位で正確）。1時間以上は `1：05：30`、未満は `36：25` |
| `{Start:m}` など | `m` = 分表記（`125：30`）／`h` = 常に 時：分：秒／`s` = 秒数 |
| `{Date}` `{Time}` | そのファイルを始めた時刻（分割したら分割した時刻）。`{Date}`=`2026-11-01`、`{Time}`=`13：05：09` |
| `{yyyy}` `{yy}` `{MM}` `{dd}` `{HH}` `{mm}` `{ss}` | 年・月・日・時・分・秒の部品（`MM`=月、`mm`=分） |
| `{DateTime:書式}` | 自由な書式（例 `{DateTime:yyyyMMdd_HHmmss}`） |
| `{ext}` | 拡張子（書かなくても自動で付きます） |
| `{Device}` `{Preset}` | 入力デバイス名・プリセット名 |

- コロンなどファイル名に使えない文字は、全角（`：` `／` など）に自動変換されます。
- 同名のファイルがある場合は上書きせず、末尾に (2) (3) を付けます。
- 録音中は仮の名前で保存し、保存時に長さ・終了時刻を確定して名前を付け直します。

### 録音が途中で止まったとき（異常終了への備え）

- 録音データはリアルタイムで書き込まれるので、アプリが落ちても途中までのファイルが残ります。
- 次に起動したとき、前回の録音が正常に終わっていなければ確認が出ます。「はい」で、長さを調べて名前の終わりに `_restored` を付けたファイルに整えます。
- デバイスが抜けたとき：初期値は同じファイルに録音を続けます（空白は無音で埋めて時間はずらしません）。オプションで「戻るまで待機」「戻ったら別ファイルに分割」も選べます。

### オプション（初期値）

無音検出での自動分割（無効）／音が出たら録音開始（無効）／グローバルホットキー（無効。`Ctrl+Alt+F9` 開始/停止、`Ctrl+Alt+F10` 分割）／予約録音（無効）／録音中のスリープ防止（有効）／デバイスの自動再開（有効）／ディスク残量の警告（5GB）と安全停止（0.5GB）。

### settings.ini

テキストエディタで開いて編集できます（UTF-8）。プリセットは `[Preset:名前]` の形で保存されます。アプリを閉じてから編集してください。

### 多重起動

同じフォルダの `LokuOn.exe` は1つしか起動できません（設定ファイルを守るため）。別のフォルダにコピーしたものは、同時に起動できます。

## 構成

- `src/LokuOn.Core` … 録音エンジン、命名、設定、FFmpeg 呼び出し（OS 非依存。`tests/LokuOn.SelfTest` で自動テスト）
- `src/LokuOn.Audio` … NAudio による入力（WASAPI / ループバック / ASIO）と再生
- `src/LokuOn.App` … WPF の画面
