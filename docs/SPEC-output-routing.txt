LokuOn 追加機能 仕様メモ（出力・ルーティング・エフェクト）
作成: 2026-11-07 / 状態: 計画（未実装）。決定事項と未決事項を分けて書く。

■ 1. 位置づけ
- 録音がメイン機能。デバイスへの出力は追加機能で、メイン画面とは別ウィンドウ。
- 使い方は3通り: 録音のみ / 出力のみ / 録音+出力。録音と出力は独立したスイッチで動かす。
- 出力を使わない人には何も変えない。出力が無効のときは追加の処理を走らせない。
- 出力側のトラブル(デバイスを抜く等)で、録音を止めない。(最重要)

■ 2. 画面
- 出力ウィンドウ: メイン画面の⚙の左のアイコンから開く。大きさ・位置を記憶。最初は空で「+ 出力を追加」から始める。
- ウィンドウを閉じても出力は止まらない。止めるのは明示的なスイッチだけ。
- メイン画面とトレイに「出力中」の表示を出す。
- メイン画面に簡単モニター用のスイッチを1つ置く(ミックスを自分のヘッドホンで聞く)。詳細は出力ウィンドウ。
- エフェクト: 入力のメーターのダブルクリック、メーター横の「FX」ボタン、右クリックメニューから開く。
  有効なときはFXボタンの色を変える。小さなパネルを1枚だけ開き、切り替えると入れ替わる。
- エフェクトパネルの機能: 上部で入力を切り替え / 設定のコピーと貼り付け / すべてバイパス。

■ 3. 音の流れ
  入力(マイク・ループバック等) → 入力ごとのエフェクト → 行列(入力×出力、ゲインとオンオフ) → 各出力のミックス → 再生デバイス
- 入力ごとに「録音に反映」「出力に反映」を別々に選べる。初期値は「出力のみ」(録音は素の音)。
- 無音による自動分割の判定は、エフェクトの前の音で行う。
- 内部は固定のサンプルレート(float)で処理し、入力ごとに既存のリサンプラで合わせる。

■ 4. 出力先
- 送れるのは再生デバイスのみ(スピーカー、ヘッドホン、HDMI、VB-CABLEのCABLE Input等)。
- 録音デバイス(ステレオミキサー、マイク)には送れない。他アプリにミックスだけを渡したいときは仮想ドライバを使う。
- ループ防止: 取り込み元にしているデバイスは出力先に選べない。画面で検出して選択不可にする。
- 出力は複数可(例: CABLEへ送りつつ、自分はヘッドホンで聞く)。最初の版は1台だけでもよい。
- デバイスごとの時計のズレは、バッファとリサンプラの微調整で補正する。目標遅延は30〜100ms。
  出力ごとに遅延が違うため、同じ部屋の複数スピーカーではずれが分かる場合がある。
- ループバックは無音のときデータが来ない。出力は途切れても止まらず、無音を流し続ける。

■ 5. アプリごとの音の分離
- 方式A(最初に採用): 各アプリの出力先を、別々の仮想デバイスにする(Windows 11のアプリ別出力設定)。LokuOnはそのループバックを入力にする。
  アプリの数だけ仮想デバイスが要る(CABLE A/B、Voicemeeter等)。
- 方式B(将来案): Windowsのプロセス単位ループバック。仮想ドライバは不要だが、元の出力にも鳴り続けて二重になる。NAudio未対応で自前の組み込みが要る。

■ 6. エフェクト
- 種類: イコライザ(BiQuad) → エコー → リバーブ(自作)。入力ごとに重ねる。
- 出力ごとのエフェクト(最終ミックスのEQ・リミッター)は、入力ごとが動いたあとに追加。
- VSTは最後。VST3のライセンス確認、.NET向けホスト用ライブラリの検証、別プロセス化(プラグインが落ちても録音を守る)を先に調査する。

■ 7. プリセット
- 出力先、行列、エフェクト、「録音に反映」「出力に反映」をプリセットに含める。
- 旧プリセットはそのまま読み込める(新しい項目は初期値で補う)。

■ 8. 進め方(段階)
 1. 内部をルーティング行列を持つ形に作り直す(見た目と録音の動作は今のまま)
 2. 出力デバイスを1つ追加する(時計のズレ補正を含む)
 3. 複数出力と行列の画面
 4. 入力ごとのエフェクト(EQ → エコー → リバーブ)
 5. 出力ごとのエフェクト
 6. VSTの調査
- 各段階の終わりにビルドして、実機で確認する。

■ 9. 確認の方法
- Linuxの自己テストで確認する: ミキサーとルーティング、エフェクトの計算、時計のズレ補正、プリセットの旧版読み込み。
- 実機で確認する: 実際のデバイス出力、アプリごとの出力先設定、遅延とズレ、ウィンドウ操作、デバイスを抜いたときに録音が続くこと。

■ 10. 未決事項
- 最初の版で出力を1台に絞るか、最初から複数にするか。
- 簡単モニターの既定の出力先(既定のヘッドホン?)。
- 出力ウィンドウの具体的なレイアウト(行列の見せ方)。
