LokuOn 波形表示 仕様まとめ(現在の実装どおり。11/8時点)

1. 役割
 - メイン画面中央の「波形」欄(WaveformView, 高さ86px)。録音中・入力確認中の音の流れを右から左へ流して見せる。
 - 録音できているかの目安であり、編集用ではない。クリックでのシーク/トリミングは対象外(保留)。

2. データ(Core/Waveform.cs の WaveformBuffer)
 - 音を 0.04秒 ごとの「区間」にまとめ、区間ごとに最小値・最大値(-1〜+1)を持つ。
 - 保持数 1500区間 = 約60秒分。古いものから消える。
 - 元の音: 入力のモノラル化 (L+R)/2。エフェクトの「録音に反映」がオンのときは、エフェクト後の音。
 - 無音分割・自動開始の判定はエフェクト前のピークを使う(波形とは別)。

3. 描画(Controls/WaveformView.cs)
 - 1区間 = 横1px の縦線(最小〜最大)。右端が最新。
 - 振幅の見せ方: |v|^0.6 でかさ上げ(小さい音も見えるようにする)。
 - 中心に水平の軸線を引く。
 - 更新: メインの33msタイマーの2回に1回(約15回/秒)。最小化・トレイ格納中は描画を省く。
 - 高さ 86px 固定、幅は欄に合わせて伸縮。枠は 1px #55808080。

4. 配色(MainWindow.xaml.cs ApplyCustomColors。テーマ変更時に再設定)
            ダーク              ライト
 背景       RGB(24,26,30)       RGB(248,249,251)
 波形       RGB(96,196,255)     RGB(20,110,200)
 軸線       RGB(80,86,96)       RGB(190,196,206)
 メーターの文字 RGB(200,205,214) RGB(70,76,88)
 メーターの消灯 RGB(60,64,72)    RGB(205,208,214)

5. レベルメーター(参考)
 - ピークホールド 1.5秒。クリップ時は赤表示。波形と同じ背景色を使う。

6. 未実装/対象外
 - 波形クリックでのシーク、ズーム、スクロール戻し、区間選択、トリミング。
 - 再生ファイルの波形表示(再生はFilePlayerで音のみ)。
 - 色・高さ・保持秒数・線の太さをユーザーが変える設定(現状は固定)。

7. 変えたいときの場所
 - 保持秒数: WaveformBuffer の capacity / bucketSeconds
 - 見え方: WaveformView の Lift(0.6)と線の描き方
 - 色: ApplyCustomColors
 - 高さ: MainWindow.xaml の WaveView Height
