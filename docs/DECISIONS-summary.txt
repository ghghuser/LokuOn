LokuOn 追加機能 決定事項まとめ(簡潔版)
2026-11-07 / 状態: 計画のみ(未実装)。詳細は docs/SPEC-output-routing.txt

[目的]
 録音がメイン。ミックスした音を再生デバイス(スピーカー・ヘッドホン・VB-CABLE等)へ出力する機能を、追加機能として足す。
 使い方は3通り: 録音のみ / 出力のみ / 録音+出力。録音と出力は独立したスイッチ。
 出力側のトラブルで録音を止めない。出力が無効のときは追加の処理をしない。

[画面]
 ・出力ウィンドウ: 別ウィンドウ。メイン画面の⚙の左のアイコンから開く。大きさ・位置を記憶。
 ・レイアウト: 「出力ごとのカード」(案B)。行列表示は作らない。
 ・全体にコンパクト: 文字12px前後、余白10px前後、入力の行は高さ30px。(モック案Bコンパクト参照)
 ・カードの中身: 名前 / 出力先デバイス / 出力中・停止 / 全体音量 / メーター / 聞かせる入力の一覧(チェック+音量)。
 ・カードは最初は1枚(ミックス1)。「出力を追加」で最大4枚まで増やせる(4枚で追加ボタンは消える)。出力は初期状態でオフ。
 ・カードの削除は、確認のダイアログを必ず出す(既定の選択はキャンセル。出力中なら止めてから消す)。保存済みのプリセットは上書き保存するまで変わらない。
 ・カードの枚数はプリセットに保存(例: 「自分だけ」は1枚、「配信」は3枚)。
 ・新しいカードの出力先は「未選択」で停止状態から始める(既定のスピーカーを自動で選ぶと、PC内部音の入力と回り込むため)。
 ・ウィンドウが狭いときはカードを折り返して2段目へ(横スクロールにしない)。
 ・入力の一覧は手動で折りたたみ可(「入力 3/4 を送信中」の1行表示)。畳んだ状態は出力ごとに記憶。
 ・ウィンドウを閉じても出力は止まらない。メイン画面とトレイに「出力中」を表示。
 ・メイン画面に簡単モニターのスイッチ(既定の出力先はWindowsの既定の再生デバイスに追従、変更可)。

[名前]
 ・入力・出力とも自由に名前を変えられ、プリセットに保存。1つの名前をメイン画面・出力ウィンドウ・エフェクトパネルで共通に使う。
 ・既定: 出力=ミックス1〜4、入力=入力1〜4(今のまま)。
 ・メイン画面に入力欄は増やさない。今の「入力1〜4」のラベルを名前の表示に置き換える。
 ・変更方法: メイン画面の名前をダブルクリックか右クリック / 出力カードの名前を直接編集 / エフェクトパネルの見出し。

[音の流れと音量]
 入力 → 入力ごとのエフェクト → 入力×出力の送り(オンオフと音量) → 出力ごとのミックス → 再生デバイス
 ・入力ごとに「録音に反映」「出力に反映」を別々に選べる(初期値は出力のみ。録音は素の音)。
 ・音量は3段階: 入力ごと(既存の−30〜+20dB) / 入力×出力ごと / 出力ごとの全体。

[出力先・入力]
 ・送れるのは再生デバイスのみ。録音デバイス(ステレオミキサー等)には送れない。
 ・取り込み元と同じデバイスは出力先に選べない(ループ防止)。
 ・アプリごとの音を分けるには、アプリごとに別の仮想デバイスへ出力し、そのループバックを入力にする(Windows 11のアプリ別出力設定)。
 ・出力デバイスごとの時計のズレは、バッファとリサンプラで補正。遅延の目安は30〜100ms。出力ごとに遅延が違う点に注意。

[エフェクト]
 ・種類: イコライザ → エコー → リバーブ(自作)。入力ごと。
 ・開き方: メーターのダブルクリック / FXボタン / 右クリック。小さなパネルを1枚だけ開く。
 ・パネルの機能: 入力の切り替え / 設定のコピー・貼り付け / すべてバイパス。
 ・出力ごとのエフェクト(最終ミックスのEQ・リミッター)は後から。VSTは最後(ライセンス・別プロセス化を調査してから)。

[プリセット]
 ・出力先、送りの設定、エフェクト、「録音に反映」「出力に反映」、名前を含める。旧プリセットはそのまま読み込める。

[進め方]
 1. 内部をルーティング対応に作り直す(見た目と録音の動作は今のまま)
 2. 出力デバイス1つ+時計ズレ補正
 3. 複数出力と出力ウィンドウ(カード)
 4. 入力ごとのエフェクト
 5. 出力ごとのエフェクト
 6. VSTの調査
 各段階の終わりにビルドして、実機で確認する。

[確認方法]
 ミキサー・ルーティング・エフェクトの計算・ズレ補正・プリセット互換は、Linuxの自己テストで確認。
 デバイス出力、アプリ別の出力設定、遅延、画面操作、デバイスを抜いても録音が続くことは、実機で確認。

[未決]
 なし。画面の細部(カードの最小幅、折りたたみの見た目)は、実装時に実機で見て調整する。
